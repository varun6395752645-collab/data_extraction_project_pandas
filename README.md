# Data Extraction Project using Pandas 📊

A beginner-friendly **Python and Pandas project** focused on extracting, cleaning, transforming, and analyzing information from raw data.

## 📌 Project Overview

This project demonstrates how **Pandas** can be used to work with real-world datasets and extract useful information from unstructured or semi-structured data.

The project includes practical data-extraction techniques such as working with strings, extracting specific information from columns, cleaning data, and creating new columns from existing data.

## 🛠️ Technologies & Libraries

* Python
* Pandas
* NumPy
* Jupyter Notebook

### 1. Data Loading

### 2. Data Exploration

### 3. Data Extraction

### 4. Data Cleaning

* Cleaning text data

### 5. Data Transformation

* Applying functions to columns
* Filtering records

* Creating calculated columns
